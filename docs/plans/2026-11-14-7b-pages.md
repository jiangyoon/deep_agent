# 7B-2 页面接入计划

**Goal:** 接入已经确认的登录页面、当前用户、退出与过期行为。

**Architecture:** 页面通过同源 HttpOnly Cookie 调用 API；shared.js 统一拦截 401，跳到带过期提示的登录页，并阻止后续匿名请求。根页面由后端校验登录后返回，前端初始化先获取当前用户，再加载会话。

**Tech Stack:** 现有 Vue 3 内联页面、Fetch、FastAPI；Node 内置 test/vm，无新增依赖。

1. 先写页面路由和 JavaScript 行为测试，观察缺少登录/跳转行为时失败。
2. 修改 view/shared.js：认证 API 请求包装器，401 后立即停止继续发请求。
3. 修改 view/login.html：真实登录、请求中禁用按钮、错误和过期提示、成功跳转。
4. 修改 view/chat.html：先取用户再加载会话、展示用户名、移动端也能退出、所有请求使用统一包装器。
5. 修改 web/app.py：未登录访问根页面跳转，已登录访问登录页跳转。
6. 执行 Python/JS 测试和编译检查，复核改动，更新 README 和交接状态。
