数据库客户端刷新表/视图结构后，可查看字段的“注释/备注”。也可直接查询指定表：

```sql
SELECT COLNAME AS "字段", COMMENT$ AS "释义"
FROM SYS.SYSCOLUMNCOMMENTS
WHERE SCHNAME = 'CAREER'
  AND TVNAME = 'KB1_REWARDS';
```

本实例的兼容视图 `ALL_COL_COMMENTS.OWNER` 返回对象所有者 `SYSDBA`，与实际模式 `CAREER` 不同，因此上述核验使用原生字典的 `SCHNAME`，避免按错误所有者过滤后误认为注释为空。

## 验证结果与边界

- 迁移包离线核验通过；写入后对11张表、1628条记录全部字段做了SHA256往返比对，覆盖原始列及展开列。
- 提交后关闭原连接，用第二个独立连接再次逐行核验通过，确认中文、换行、CLOB长文本及空值未在迁移中改变。
- 12个主键、14个外键、2个唯一约束均为启用状态。9个视图全部可查询。
- 一建样例核对结果为机电12000元、公路工程及水利水电8000元，注册补贴500元/月，与源记录一致；这些是2025年目录原文，当前是否沿用仍待业务确认。
- 两条对应冲突记录仍隔离，普通对应关系视图只返回156条。
- 421条检索文本的Embedding状态仍为待接入，非空向量数为0。
- 报名模板未解析正文。只迁入文件元信息、版本和关联，文件原件仍在本机；表中的本机路径不是可供浏览器直接下载的URL。
