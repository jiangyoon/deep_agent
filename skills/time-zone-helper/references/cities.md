# 支持的城市与时区

get_current_time 工具目前支持下面这些城市。表里是标准时间和夏令时的 UTC 偏移。

| 城市 | 标准时间 | 夏令时 | 说明 |
|---|---|---|---|
| 北京、上海 | UTC+8 | 无 | 全年不变 |
| 东京 | UTC+9 | 无 | 全年不变 |
| 纽约 | UTC-5 | UTC-4 | 美国夏令时：3 月第二个星期日开始，11 月第一个星期日结束 |
| 洛杉矶 | UTC-8 | UTC-7 | 同上 |
| 伦敦 | UTC+0 | UTC+1 | 欧洲夏令时：3 月最后一个星期日开始，10 月最后一个星期日结束 |
| 巴黎 | UTC+1 | UTC+2 | 同上 |

工具返回的时间里已经带有当前生效的 UTC 偏移，换算时直接用它，不需要自己判断是否夏令时。
