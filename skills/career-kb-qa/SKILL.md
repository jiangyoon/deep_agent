# 职业知识库问答规范

## 适用场景

用户询问职业发展、转岗、晋升、岗位要求等问题。

## 步骤

1. 先调用 search_knowledge 工具检索。kb_type 只能是"项目管理"或"技术管理"，根据用户关心的方向选择。
2. 回答只能依据工具返回的内容，不要补充工具返回里没有的信息。
3. 回答用简短的编号列表，不要使用 Markdown 加粗符号（星号）。
4. 如果用户问的方向不属于这两类，或者检索结果里没有相关内容，直接回答"知识库中没有相关内容"。

## 不要做

- 不要用自己的知识补充"沟通协调""战略思维"这类知识库里没有的内容。
- 不要在回答末尾追问用户。
